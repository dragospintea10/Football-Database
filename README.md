# Football Database SQL Project

This project is a relational database system developed as an academic project.
The database was designed to manage football-related information, including clubs, players, competitions, seasons, matches, transfers, lineups, managers, actions, statistics and trophies.

## Technologies Used

* SQL
* Relational Database Design
* Primary Keys and Foreign Keys
* Views
* Functions
* Triggers
* Stored Procedures
* Data Integrity Constraints

## Project Description

The main objective of this project was to design and implement a relational database capable of storing and managing football data in a structured and consistent way.

The database includes entities such as players, clubs, competitions, seasons, matches, transfers, lineups, managers, actions, statistics and trophies. Relationships between these entities were created using primary keys, foreign keys and indexes to ensure data consistency and relational integrity.

## Main Features

* Creation of relational tables
* Definition of primary keys and foreign keys
* Use of indexes to improve database structure and access
* Management of relationships between players, clubs, matches, competitions and seasons
* Creation of SQL views to simplify data consultation
* Development of functions to retrieve specific player and club information
* Implementation of triggers to automate database updates and enforce business rules
* Creation of stored procedures to calculate and insert player match statistics

## Files

* `schema.sql` — contains the database structure, including tables, keys, indexes and relationships.
* `database-programming.sql` — contains SQL views, functions, triggers and stored procedures.
